组件三层合成：① 背景（主题渐变 / 纯色 / 上传图片）② 标题+副标题（可居左或居中；可设「手机前方 / 手机后方」选择遮挡关系）③ 手机动画视窗（方形，可在屏幕左 / 中 / 右）。全部在 ④ 合成图层 页卡里调，弹窗里看到的是完整 banner 等比缩小后的实时效果。
标题文字：把 #titleInput / #subInput 的默认内容改成你的文案即可；手机 UI 图把屏幕里 .ui 的 src 换成你的图。
进场动画配置（页卡式两点，每台可独立）：① 起点视角 / ② 终点静止 拖 X/Y 调该点；2 台时点页卡右上「手机 A / 手机 B」分别调——两台能做起停镜像、高低错落（终点页卡「高低偏移」）。点 ↔ 让 B 镜像 A 一键让 B 的 X/Y 取 A 反向做对称镜像。点「重播进场动画」即自动跑各台 start→end 过渡（rAF 驱动，全程侧壁厚度可见）。
全局缩放（③ 旋转设置页）：缩小时把因高低偏移/间距/前后景深超出视口的手机整体收进框内，只缩 X/Y 不影响透视景深。
