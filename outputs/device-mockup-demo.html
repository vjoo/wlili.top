代码套壳样机 · 真圆角厚度 iPhone（灵动岛）

外壳为沿 Z 轴堆叠的圆角薄片挤出体，旋转 360° 全程看得到侧壁厚度与圆角、无方角；侧键齐全。进场从下方整圈旋转上升、播一次。

嵌入你的 UI：把屏幕里的 <img class="ui" src="..."> 的 src 换成你的图即可。切口、灵动岛、圆角厚度自动适配。
侧壁厚度用「圆角薄片沿 Z 轴堆叠」实现（手机 28 层 / 笔记本 18 层），所以 360° 旋转时侧壁是连续的实心圆角边，不会像六面体那样露方角。
进场「从下整圈旋转上升、播一次」：CSS @keyframes 用 translateY(480px)→0 + rotateY -382°→-22°（正好转一圈）+ forwards 落定。
动画库：单元素播一次 CSS 足够；要「滚进 banner 视口才播 / 多元素时间轴 / 弹性缓动」用 GSAP + ScrollTrigger（你指定的动效库），可随时转。
