# 2026-08-22

## tools/school-calendar.html 优化
- 学期/假期时间判断修复：原 `renderCalendar` 用所有假期起点最小值作学期终点，会误把秋假/春假（学期中短假）当终点截断日历。改为只取终止性假期（T1=寒假、T2=暑假）起点作边界。
- 寒假/暑假起点改为 `endDate + 1`（学期结束次日开始放假），与“时间安排参考”文案一致；副标题显示真实最后上课日。
- 新增校验：终止性假期须晚于开学；短假须落在开学与学期结束之间。
- 移动端交互：桌面/打印保留 A4 表格；≤600px 隐藏表格，改为竖向“周卡片”列表（JS 同时生成两份 DOM，renderCalendar 重构）。
- 学年选择 UI：原 `<select>` 只有 2026 一个选项。→ 第一次误改成步进器+chips，**用户反馈改错地方（学年下拉本来是好的）**，已还原为原 `<select id="yearSelect">`。
- 「年份难选」的真相：用户指的是**表单里的日期输入框**（开学/报到/寒暑假起止/秋假/春假/自定义标注）用原生 `<input type="date">`，手机上是滚轮、年份要一直滑、很隐蔽。
- 修复方案：新增 `convertDateInput()` 把原生日期框替换为「年/月/日」三段 `<select>` 下拉（年份单独成块、点按即选），保留隐藏镜像 `<input id=原id class="... date-mirror">` 沿用 `.value`，既有读取/校验/校验报错逻辑零改动。
- 关键衔接：`updatePreset()` 程序化赋值时通过 `refreshAllDateFields()` 把隐藏 `.value` 同步回三段下拉；`displayEl()` 让报错高亮落到 `.date-field` 外层；空值保留（不默认填日期，避免误显假期）。
- 移动端：`.breaks-range` 在 ≤600px 改为起/至/止各占一行，避免 6 个下拉挤一行。
- 桌面端假期标题/日期同行的 bug：`.breaks-row` 原 `align-items:center; gap:16px`（标题与起/至/止同一行），年份下拉被挤成 "202..."。改为 `flex-direction:column; align-items:stretch`，标题独占一行、日期区间在下方整行，年份 "2026年" 完整显示。与移动端“上下两行”观感统一。
- “+添加标注”按钮从右侧移到左侧「自定义（生日、考试时间等）」标题之前。
- 时间安排参考新增「共 X 周」：新增 `countWeeks(reg,start,vacStart)`，算法与 `renderCalendar` 的 totalWeeks 完全一致（min(报到,开学) 的周一 → 放假起始日所在周周日，ceil(天数/7)），保证参考标题周数与日历副标题一致。T1=22周、T2=21周。
- 标签配色与字号：国家法定节假日（中秋/国庆/元旦/清明/劳动/端午，type:'holiday'）改橘色 `#ffa617`（深棕字 #3a2600 保证对比）；学校假期（寒暑假/春秋假）原也用 type:'holiday' 混在一起，改为 `expandDateRange(...,'break')` 独立染红 `#d32f2f`（新增 `.tag-break`）。无需改几百行预设数据。标签字号 10px→12px（桌面+移动周卡片统一），去掉 `transform:scale(0.9)`。
- A4 边距收紧：屏幕 `.a4-paper` padding 15mm→12mm；打印 `@media print` padding 8mm 10mm→6mm 8mm。估算 2026 T1（22周，约261mm 内容）在 273mm 内容区（12mm 边距）内可容纳，留约12mm 余量，不超 A4。
- 移动端日历改回与打印一致：用户反馈竖向周卡片「不好看、和打印差别太大、会误导人」。将 ≤600px 块的 `.cal-table{display:none}` 改为 `display:table`、`.a4-paper` 恢复 `210mm` 宽（可横向滑动）、隐藏 `#mobileCal`、显示 `.scroll-hint`。即移动端直接显示与打印/桌面一模一样的 A4 表格。原周卡片 CSS/JS（`#mobileCal`/mobile-week 等）现处于 dormant 状态（hidden），未删除以免误伤。
- 鸿蒙浏览器兼容（年份被截断「2…」）：① 年份 option 文字 `yy+'年'` → 纯数字 `yy`；② `.date-field` 在 ≤600px 改 `flex-wrap:wrap`，年份 select `.df-year{flex:1 1 100%}` 独占一行、月日各半行；③ `.breaks-range` 在 ≤600px 改 `flex-direction:column`（原 `flex-wrap+flex-basis:100%` 在鸿蒙不稳，导致起/止仍并排），起/至/止 竖向堆叠，每个日期框整行宽、年份再独占一行。彻底解决截断。
- 日历格子等高：`.cal-table td:not(.col-week)` 原 `height:38px` 但标签 baseline 对齐 + 多标签撑高导致行高不齐。改 `height:44px; vertical-align:middle; line-height:1.3; overflow:hidden`（保留 table-cell 默认行为，居中 + 防撑高）。⚠️ 注意：曾试过 `display:flex` on `td`（flex-direction:column 居中），但在鸿蒙/部分浏览器下 table-cell 改 flex 会导致表格渲染错乱（行高异常/内容错位），已回退，勿再用 flex on td。
- 第一周规则：**开学的周才记第 1 周**（用户明确要求）。报到若在开学前一周的周日，旧逻辑 min(报到,开学) 会把报到周当作第1周 → 错。改法：`firstTeachingMonday = getMonday(开学日)`，日历起点仍取 min(报到,开学) 的周一（保留报到显示），循环内按 `weekMonday < firstTeachingMonday` 标「报到」、否则按 `(weekMonday-firstTeachingMonday)/7+1` 编号；`totalWeeks`（副标题共X周）改为从 firstTeachingMonday 起算；`countWeeks()` 同步改以开学日为起点（去掉 min 逻辑）。`vacMonday = teachingLastSunday+1` 判假期周。
- 教学周边界修正（T2 bug）：暑假 2027-07-05 恰为周一，旧逻辑把该周算作「第20周」但整周无课。新规则：**放假起始日若为周一 → 教学周止于前一周日（该周整周无课不算教学周，直接进入假期行）；放假在周中开始（周二~周日）→ 该周仍算最后教学周**。renderCalendar 的 `endEnd` 与 `countWeeks` 同步此逻辑。T2=19周、T1=22周（寒假周六开始不受影响）。
- 假期标签精简：寒假/暑假跨数十天，逐日红字太乱。新增 `sparseBreakRange()` 只生成起止两天标签（「寒假开始/寒假结束」「暑假开始/暑假结束」），中间日期无标签；秋假/春假较短保持逐日标注（`expandDateRange`）。breakDefs 加 `sparse:true` 标志区分。格子无 break 底色类，中间日期显示为普通月交替底色。
