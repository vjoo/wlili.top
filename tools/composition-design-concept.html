构图编辑器 v2 · 设计概念

解决两个核心问题：① 主体内容（荷花/龙/天宫）不写死，由「种子词 + 知识库 + AI」生成；② 前景遮挡与画面纵深的可用控制。

一、先把“在哪”和“是什么”拆开

当前工具把几何和内容焊死在一个框里（框里直接写死 giant white lotus…）。正确做法是把一个区域拆成三层，只让内容和几何各自独立演化。

二、“是什么”的三条流程（内容层怎么填）

工具只负责几何和角色，内容层有三种填法，从最轻到最智能：

模式用户做什么AI 做什么适用
角色词库选角色 + 从下拉挑主体（莲花/古树/巨石/龙…）不调用，按预设模板拼接常见题材，离线、零延迟
种子 + 扩写框里只写 龙 或 莲花角色 + seed + 知识库锚点 → 生成完整提示词，用户可改默认模式，灵活且可控
一句话反推写一句 brief（如“东方巨物，莲花上行走的宋装女子”）拆解成区域 + 提议几何 → 用户在画布上微调从想法起步，最顺手
关键：知识库（东方巨构材质词典、巨物奇境六维池）只作为“风格锚点”被引用，不写死在 JS。你更新知识库，未来所有扩写同步受益——内容永远活在你的知识库里，工具只是取用。

三、前景遮挡 + 画面纵深的可用控制

把“深度”做成一等维度，而不是只用一个 z 整数：

深度档：前景 / 中景 / 背景 / 超远，各自自动带透视语言
前景遮挡：类型=前景且压住后面区域(z 更高) → 自动加“浅景深 / 失焦 / 部分遮挡”
纵深计：统计层次数 + 重叠 + 尺度梯度 → 浅/中/深评分

纵深的 5 个可控制线索：① 遮挡重叠（重叠 + z）② 尺度梯度（同类物体沿退远轴缩小，如 D3 的百层柱列）③ 大气透视（深度档→雾化）④ 透视收敛（可拖一条“视线/灭点”轴线）⑤ 层次数量。

诚实边界：单 pass 区域提示词无法真遮挡。前景框压住主体，在一次扩散里模型只会“影响”而不会可靠地把后面的东西藏起来。真正的遮挡必须分层生成：从后往前逐层渲染、每层独立 pass + mask、再合成。所以 B 导出应是“深度有序的层栈（带 mask）”，对接 ComfyUI 分层工作流——这才是前景遮挡与纵深感的真正落地机制，也正是之前说“路径 B 才是目标”的硬理由。

四、建议的区域数据模型

字段类型说明
role枚举subject / character / sky / foreground（结构层，固定）
seed字符串用户给的内容种子，如“龙”“莲花”（可空）
prompt字符串AI 扩写后的成品提示词，可编辑
geometry对象x/y/w/h(%), z, cross, depthTier
anchors数组从知识库拉取的风格锚点（材质行为词等）

五、下一步

概念确认后，v2 的实际改动是：在现有编辑器上加「内容层（seed + AI 扩写按钮）」、「深度档选择器 + 纵深计」、「前景遮挡类型」，并把 B 导出从“平面 region”升级为“深度有序层栈（带 mask）”。要不要我直接动手做 v2 原型？
