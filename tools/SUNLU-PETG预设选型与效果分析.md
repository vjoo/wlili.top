## 2. 场景 × 预设 速查矩阵

| 你要打的模型                    | 首选                     | 关键理由                                           | 次要调整                      |
| ------------------------- | ---------------------- | ---------------------------------------------- | ------------------------- |
| **快速原型 / 批量小件**           | ⑤⑨（基础款默认速度）            | 不追极速，稳打即可                                      | 多色靠 ⑨ 流量校准保尺寸一致           |
| **摆件 / 手办 / 雕像**（悬垂多、细节密） | ⑤⑨ + ⑥ 质量思路            | 基础款稳打 + ⑥ 桥接/墙数加固                              | 悬垂靠 ① PLA 思路或风扇 50%，勿硬套强冷 |
| **大型 / 高件**（怕翘、怕掉板）       | ⑦（待补）→ 暂用 ⑤⑨           | 床 75–80℃ + 风扇 40–50% + 墙 3 层                   | ⑦ 补录前用 ⑤⑨ 顶替，PETG 必涂离型剂   |
| **受力功能件**（卡扣、支架、户外件）      | ⑤⑨（**降风扇**）            | 风扇 40–50% 保层间结合                                | 墙 3 层、外层/顶面速度再降一档         |
| **大桥接 / 无支撑跨度**           | ⑥ V3 思路                | bridge_speed 40（极端 Flow 1.4 / Speed 10）        | 慢而稳                       |
| **追求顶面镜面**                | ⑤⑨ + 开熨烫               | ironing_flow 15%（工艺档开 `ironing_type`）          | 先小范围试；⑩ 已含同心熨烫图案          |
| **薄壁 / 半透明部件**            | ⚠️ 慎用强冷                | 强风会让薄壁层间分层、透明度下降                               | 风扇降到 20–30%               |
| **普通三绿 PETG（基础款）**        | ⑨ 流量校准 / ⑤ White Basic | vol 上限 15–22 + 245–270℃                        | ⑨ 修正流量、⑤ 做温度参考            |
| **桥接多 / 精细螺纹**            | ⑥ V3 bridge 值          | 合并 V3 桥接设定                                     | 别同时叠两个完整预设                |
| **普通三绿 PETG Basic（流量校准）** | ⑨ + 任意工艺预设             | `flow=1.045` 修正实测吐量偏差，尺寸更准、棱角更清晰               | 配 ⑩ 字体工艺可打小字/徽标           |
| **字体制件 / 小字细线 / 徽标**      | ⑩ + ⑨（或任意耗材丝）          | `arachne` 变宽挤出 + `0.16` 层高，细墙更饱满不断裂；关圆弧拟合让小圆更圆 | ⑩ 是工艺预设，与耗材丝预设正交，可与 ⑨ 搭配  |
| **蜂窝孔壁 / 翻边 / 大跨桥（悬垂桥接多）** | ⑨ + ⑪（悬垂桥优化）        | ⑪ 满冷 + 厚桥 + 桥速 25 专治孔顶棚悬垂与桥面下塌           | ⑪ 是冷却/桥接正交层，叠加 ⑨ 不冲突       |

> ⚠️ **重要**：①/②/⑤/⑥/⑨/⑩ 之间**只套一条完整预设**，混着套会互相覆盖（比如风扇策略冲突）。**唯一例外是 ⑪**——它是纯冷却/桥接调优层，只改悬垂风扇/强制冷却/厚桥/桥速/温度，可与 ⑨（流量校准）或 ⑤（温度参考）安全叠加（合并其 `filament.overrides` 即可）。

## 3. 最优参数选择：决策树与推荐值

### 3.1 先回答三个问题

```
1) 你的料是哪一款？（你只用基础款，高速 Rapid 不录入）
   ├─ 三绿 **White Basic**（普通）      → 走 ⑤（补全后）
   ├─ 三绿 **Basic 已流量校准**         → 走 ⑨（flow 1.045）
   └─ 其他/未知                       → 用下面的「保守通用档」

2) 你的热端是什么？（决定上限，基础款按通用 PETG 能力）
   └─ 标准 0.4 喷嘴      → vol 上限 **15–22**，回抽 0.4，245–270℃

3) 你的模型要什么？
   ├─ 追表面/细节      → 加速度降到 8000，悬垂风扇 50%
   ├─ 追强度/耐久      → 风扇降到 40–50%，墙 3 层，桥 40
   └─ 追速度（基础款范围）→ 内部填充可略提，但别超 vol 22
```

## 4. 本次顺带修掉的一个真实 Bug

在校验过程中发现：`bambu-preset-patch.js` 第 61 行构建耗材丝索引时，把 `options` 统一按**字符串**处理，而 `cooling_slowdown_logic` 这类字段用的是 **`{v,l}` 对象**（`v`=官方内部键、`l`=中文标签）。结果是：**写 `uniform_cooling` 或写 `均匀冷却` 都会被误判为非法枚举并报 warn**。

已修正为兼容两种写法。影响：所有带中文标签的耗材丝下拉项（如冷却减速逻辑）现在能被正确识别，`uniform_cooling` 恢复 ok 状态。
