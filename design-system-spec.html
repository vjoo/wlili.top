10

设计盲区 · 未覆盖角落

以下维度在现有 Token 体系中完全缺席，仍靠散落硬编码维持。每个都附真实频次证据、风险与建议 Token、优先级（H 高 / M 中 / L 低）。

A · 字号阶梯

20+ 个不同取值H

font-size 散落 12–148px 与多个 clamp()，无统一阶梯，跨页标题层级易漂移。

建议：--fs-display / h1 / h2 / h3 / h4 / body / sm / xs，按用途聚类而非按像素。

B · 行高

12 档 (1.05–1.7)H

行高裸写，标题与正文混用，长文可读性靠巧合。

建议：--lh-tight / snug / normal / relaxed。

C · 字距 Letter-spacing

15 档 (-7.4px…+0.08em)H

大负数 px 字距绑定超大显示字，零散且不可复用；eyebrow 的 +em 字距未统一。

建议：--tracking-tightest / tight / normal / wide。

D · 字重

8 档 (300–900)M

仅字体族有 token，字重裸写。主力是 600/500/400，但 800/900 偶发，易破坏视觉节奏。

建议：--fw-regular/medium/semibold/bold。

E · 统一间距体系

gap 10+ 种裸值H

只有区块留白四档；组件内 gap/margin 全是 1rem/24px/20px… 无基准尺度，改间距要满文件找。

建议：--space-1…12（4px 基准）+ --gap-* 语义别名。

F · 容器宽度

1520px / 680px / 560px…M

主容器 1520px、正文阅读宽度 680px 等裸写，响应式下无统一 max-width 语义。

建议：--container-max(1520) / --container-text(680)。

G · 透明度层级

0 / .5 / .55 / .6 / .85M

disabled / hover / overlay 的 opacity 裸写，缺少语义命名。

建议：--opacity-disabled/.muted/.soft。

H · 深色组件表面色

#0f0f11/#14161a/#1c1c22/#2a2a2aH

真实盲区：深色模式 Token 只反转了"页面底/文字/卡底"，但暗色下的组件表面（深卡、深块背景）用的是一批未管理的 hex（#0f0f11、#14161a、#1c1c22、#2a2a2a、#1a1a1a），与 --color-white→#1a1a1a 重叠却各自为政，深色主题无法一处调。

建议：新增 --color-surface-dark-1…4 收纳这批深色表面，并让梯度（I）引用它们。

I · 渐变 Gradients

13+ 种写法M

深色 hero/卡渐变（#2d2d44→#1a1a2e、radial #1c1f25→#0c0d1x）、浅色遮罩、奶油渐变（#c8b8a8→#e8dcc8）全部裸写，且绑定了盲区 H 的未管理深色。

建议：把高频渐变提为 --grad-dark-hero / --grad-dark-card / --grad-overlay-light。

J · 响应式断点

1024/768/767/900/480/1500M

存在隐患：同时使用了 max-width:768px 与 max-width:767px（×5 与 ×2），off-by-one 会导致同一视口命中两套规则。无命名断点。

建议：--bp-sm(480)/md(768)/lg(1024)/xl(1500)，并统一 768（弃用 767）。

K · 宽高比 Aspect-ratio

4/3·4/5·16/9·1/1…L

布局型比例（4/3、4/5、16/9、1/1、5/3）可 Token 化；但 1136/608、1448/905 等是图片原生比例，应保留硬编码。

建议：仅把布局比例提为 --ratio-*，图片原生比例不碰。

L · 交互态色彩

hover/focus/active 未系统管理L

按钮 hover 背景、焦点环(focus-ring)、active 态多为局部硬编码，未与 token 联动。

建议：--state-hover / --state-focus-ring，复用 accent 与 surface。

🟡 完整性 · 已落地 token 未接线

#fff×23 / #0a0a0a×13L

并非新角落，而是"已有 token 但组件里仍写死字面"：#ffffff×23、#0a0a0a×13、#888888×5 等。零视觉风险，但削弱单一源纯度。

建议：一次性全量替换为对应 var()（可用脚本安全替换，带 fallback）。
优先级建议（先做高 ROI）：
① A+B+C+D 排印四件套 + E 间距体系 —— 这五项覆盖 80% 的"视觉不一致"来源，且彼此关联，建议打包成一次"排印与间距基础"收口；
② H 深色表面 + I 渐变 —— 解决深色主题无法一处调的真问题；
③ J 断点 顺手修掉 767/768 冲突；
④ F/G/K/L 与 🟡 完整性清理 —— 收益递减，按空闲推进。
