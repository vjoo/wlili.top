12一致性待收敛

以下为现场核对发现的、与「主系统青柠绿」不一致的残留。A/B 与下列三项均已收敛（2026-10-09）；本节作为收敛记录留存。

✓
子组件聚焦/选中色写死靛蓝回退 #6366f1 日历(.cal-day)、下拉搜索(.sel-search-input)、取色器(.form-swatch/.form-range)、表单聚焦(.form-input:focus) 等用 var(--accent-color)（无回退 → 失效）与硬编码 rgba(99,102,241,.1) 环。 已收敛（2026-10-09）：:root 补 --accent-color:var(--accent)（实色绿）与 --accent-ring:rgba(132,204,22,.18)；焦点环 rgba(99,102,241,.1) 全量替换为 --accent-ring。子组件聚焦/选中/滑块/取色器统一转绿，靛蓝环清零。状态色 #6366f1（SD 买断 / 收入图表）属语义数据色，保留。
✓
主按钮类名两套并存 .btn.primary 与 .btn-primary 已收敛（2026-10-09）：合并为单一规则 .btn.primary, .btn-primary（绿渐变 + 白字 + 胶囊 999px，padding 10/18、13px，含 hover/active/disabled）；删除 line 890 发散实色圆角定义、.sp-wrap .btn-primary* 覆盖及 11996 区重复定义。SP 模块按钮尺寸（原 8/16、14px）与外壳统一为 10/18、13px。HTML 无需改动（两类名等价）。
✓
次级按钮尺寸分歧 & 小按钮类名错配 已收敛（2026-10-09）：① .btn-secondary 实为两段裸定义——全局 8/16+radius-md（被覆盖的死代码）与文件更后的 10/18+999px 胶囊（生效）。删除死定义，单一来源 = 胶囊 10/18（与 .btn.primary 同形），零视觉变化。② HTML 三处 class="btn sm"（空格，L3849/4142/4914）无对应 CSS → 小号未生效；改为 class="btn btn-sm" 命中既有 .btn-sm（padding 7/14、12px），三个按钮（显示全部 / 看预设 / 清除并重新选择）恢复应有的小尺寸。
✓
字阶跳档（15→22 缺 16–21） 已收敛（2026-10-09）：:root 补 --fs-16~21（16/17/18/19/20/21px），15→22 主缺口闭合、标尺连续（§04 已同步标本）。23–26、28–33 仍属 legacy 大跳档，留待后续；新代码一律用 --fs-*，不散写裸值。
✓
断点集合较碎（1280/1200/1024/900/820/768/734/560/480 共 9 个） 已收敛（2026-10-09）：:root 沉淀命名断点 --bp-mobile:480 / --bp-xs:560 / --bp-phablet:734 / --bp-tablet:768 / --bp-netbook:820 / --bp-md:900 / --bp-laptop:1024 / --bp-lg:1200 / --bp-xl:1280（§10 已列出），供人工对照与 JS matchMedia 引用。 ⚠ 纯 CSS @media 条件不能用 var()——下方各 @media 仍写裸值，未替换为 var(--bp-*)（否则媒体查询整体失效）。真正令牌化需 JS 驱动 matchMedia 或构建步骤，当前零构建，未做（避免破坏）。
